# Web UI Application

The `@mindfiredigital/adac-web` package provides a browser-based, interactive interface for writing ADAC architectures.

It utilizes the `@mindfiredigital/adac-diagram` module internally to generate real-time diagram previews, cost estimations, and compliance checks as you type.

## Running Locally

```bash
npx @mindfiredigital/adac-web
```

This starts a local server on port 3000 where you can write YAML and immediately see the results.

## Ignix UI Integration

The ADAC Web UI is built using the gorgeous `@mindfiredigital/ignix-ui` component library, ensuring a premium, sleek developer experience.
